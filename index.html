How it works

From plug-in to live OEE in minutes.

Connect

Point FACTS at a machine's endpoint and browse its live address space in the app. Auto-detected profiles map the OEE signals for you — confirm and save.

In-app OPC-UA / MTConnect browser

Measure

FACTS records on change, computes A×P×Q per machine, and keeps the history on-site — with downsampling so a small SQL Express never fills up.

Records · rolls up · never guesses

See

Live gauges, state timelines, downtime Pareto and per-shift OEE — on any screen on the plant network, or a full-screen kiosk beside the machine.

Dashboards · kiosks · ERP API
What's inside

Everything on one box. Nothing phones home.

Address-space browser

Add machines by clicking nodes — no vendor tools, no config files, no guessing tag names.

Machine profiles

Map any machine once, reuse it for every identical install — whatever the make.

Live dashboards & kiosks

OEE gauges, state timelines, downtime Pareto. Build custom views, rotate them on a wall display.

Offline-first appliance

Runs on a slim PC or Raspberry Pi 5 on the plant network. No internet required, ever.

SQL Server & ERP API

Forwards to your existing SQL Server; a read-only REST API feeds OEE straight into your ERP.

Signed OTA updates

Upload a signed package; the box verifies, applies and auto-rolls-back if the new build isn't healthy.

The appliance

A quiet box on the wall. That's the whole install.

Sized for storage endurance and dirty factory power, not spec-sheet horsepower. Plug it in, give it a name, add your machines — it starts collecting on boot and keeps a durable record on-site.

  • HardwareFanless industrial mini-PC (Intel N100) or Raspberry Pi 5
  • PowerWide-voltage DC · clean shutdown on power loss · watchdog
  • NetworkPlant LAN only · gwb-oee.local · self-signed HTTPS
  • StorageLocal buffer + roll-up · years of OEE in 10 GB
  • AccessAnonymous viewer · user admin · GWB technician
